# 桌宠动作素材

使用内置图像生成工具，原图 `blue-slime-pet.png` 为严格角色参考，不覆盖原素材。提示词要求蓝色透明果冻材质、额头星光、腮红、无手脚、透明 PNG 背景和参考原图画布；运行时统一 CSS 画框对齐。

- `blue-slime-pet-frontflip.png`：前空翻收身姿势，身体蜷成圆球向前倾，水滴尖端折向脸前，闭眼蓄力；不是原图的平面旋转。
- `blue-slime-pet-backflip.png`：后空翻收身姿势，圆润身体向后倾，脸朝上、兴奋大眼，水滴尖端向头后方弯曲；不是原图的平面旋转。

运行时分别使用正反方向的透视 X 轴旋转，再恢复原站立素材。
