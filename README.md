# Yu-s-Ai-plugin-platform
雨的ai插件平台

Ai plugin platform api

描述：这是一个能够支持多插件的api调取平台，和其他平台不同，该平台不能直接做什么操作，多是辅助类功能，比如翻译插件，角色卡聊天插件，记忆压缩存储等，对于我来说这是足够的辅助。我不用在网页上被限制长度，也不用打开别人的平台却只能聊天，我也希望我能将该平台做成PC/PE端互通，这样我能足够的方便。我喜欢个人化DIY工具。

Description: This is an API-based platform that supports multiple plugins. Unlike other platforms, it doesn't perform direct actions itself; instead, it offers utility-style features—such as translation plugins, character card chat plugins, and memory compression/storage—which provide exactly the kind of assistance I need. It frees me from character-limit constraints often found on web interfaces and avoids the limitation of platforms that restrict you to just chatting. I also hope to make this platform cross-compatible between PC and mobile (PE) for maximum convenience. I simply love tools that allow for personalized customization.
