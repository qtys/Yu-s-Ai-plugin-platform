# Yu's AI Plugin Platform

Yu's AI 是一款本地优先的 Windows 私人 AI 聊天工具。它将角色扮演、多模型 API、长期记忆、离线翻译和桌面宠物整合在同一个应用中，并为后续插件能力预留扩展空间。

当前版本：**0.13.6**

## 0.13.6 版本亮点

- 主动发言仅保存在本地用于查看，不再随聊天上下文上传给模型。
- 消息增加来源标记，主动互动生成新话题时也不会引用之前的主动发言。

### 0.13.5

- 手动发消息会立即取消正在生成的主动发言，避免主动内容插入或打断当前对话。
- 随机主动发言可设置最短与最长等待时间，每轮在区间内重新抽取时间。
- 展开界面的消息编辑器改为主题化卡片布局，支持 `Ctrl + Enter` 保存、`Esc` 取消和字数提示。

### 0.13.4

- 展开界面使用稳定的流式消息标识与自动滚动，修复多轮对话后回复不显示或写到其他消息的问题。
- 手动对话和主动发言互斥执行；主动发言按服务端到期时间调度，保存新间隔或用户手动发言后都从当前时刻重新计时。
- 主动发言失败保持静默，只记录日志及设置状态；模型无正文和流式格式异常则在手动对话中明确提示。

- 后端改为目录式打包，依赖直接安装在 `backend-runtime`，不再每次启动向 C 盘解压数百 MB。
- 退出先请求后端正常关闭、刷新数据库和日志，超时才强制结束；后端临时文件使用安装目录 `data/temp`。
- 提供旧临时运行库的谨慎清理脚本，仅处理启动日志与指纹匹配且未占用的目录，默认只预览。

- 修复主动发言气泡丢失：生成过程中打开面板或拖动后，等待空闲再显示。
- 空正文失败显示明确提示并统计已消耗 token；前两次约 60 秒后重试，连续失败至少间隔 5 分钟。
- 回复额度支持 64–8192 tokens，旧默认 160 自动升级为 1024；推理模型仍空回复时可手动提高。重试也可能计费。

- 主动发言间隔 1–1440 分钟，可选固定或随机模式，修改后同步调整冷却。
- 主动发言优先遵循角色身份、口吻、兴趣和边界，最近对话优先，避免通用助手台词。

- 前空翻、后空翻独立透明动作素材与透视动画
- 可开关的角色主动互动模型插件，按完整角色卡和时间生成问题、笑话
- 可选近期 RSS 新闻话题、调用冷却、输出 token 上限与用量统计

- 离线语言包下载新增实时进度条，分别显示下载、安装、完成和失败状态
- 展开界面的模型设置支持自定义语言包镜像地址，留空继续使用 Argos 官方源
- 下载与模型安装在后台执行，不阻塞本地 API 的其他请求

## 主要功能

### 私人 AI 对话

- 支持 OpenAI Chat Completions 兼容接口，可连接 DeepSeek 等兼容服务
- 支持流式回复、停止生成、多会话和本地历史记录
- 可配置 API 地址、API Key、模型名称、温度和最大输出长度
- 最近对话支持重命名和删除
- 用户消息与 AI 回复均可修改，后续对话会使用修改后的内容作为上下文
- 模型设置提供 Markdown 渲染、Markdown 过滤和原始文本三种消息显示插件
- 提供暮紫、午夜蓝、暖砂和纸墨四套界面主题

### 角色卡与记忆

- 角色卡支持头像、开场白、身份背景、性格、说话方式、用户关系、行为边界和示例对话
- 结构化角色信息会自动生成系统提示词，也可继续填写自定义提示词
- 支持创建、编辑、删除，以及 JSON 格式的角色导入和导出
- 可手动设置最近上下文消息数（2–200）和相关长期记忆条数（0–50）
- 长对话会保留较早内容摘要，并按角色隔离长期记忆
- 可从用户明确要求记住的信息中提取姓名、偏好和个人资料，并按当前话题选择相关记忆

### 蓝色雨滴桌宠

- 应用启动后默认显示透明、无边框且始终置顶的蓝色史莱姆桌宠
- 桌宠会轻微朝鼠标方向偏转，点击时播放弹性挤压和水波反馈
- 按住桌宠即可拖动，拖动时身体拉伸、松手后回弹；靠近屏幕边缘时自动吸附
- 桌宠位置会在下次启动时恢复，闲置时会随机摇晃、挤压或犯困
- 模型和翻译成功后播放开心动作，发生错误时播放疑惑动作
- 可显示喝水、久坐休息等主动关怀冒泡，并能在“设置”功能圈中关闭
- 可拖动气泡侧边和上下边缘手柄调整对话框宽高，也可在桌宠设置中精确调节并保存
- 桌宠点击判定区域贴近史莱姆主体，减少透明边缘对桌面操作的干扰
- 单击桌宠展开功能圈；五个功能圈从正下方开始沿 180° 半圆等距环绕桌宠
- 双击未展开功能圈的桌宠，可直接打开上一次使用的对话、翻译或设置面板
- 对话、翻译等面板可以独立关闭，隐藏区域不会继续拦截桌面点击
- “设置”功能圈集中提供桌宠大小、透明度和对话文字大小调节，选择会自动保存
- 面板打开和关闭时会同步切换原生窗口与界面布局，避免桌宠和气泡跳动闪烁
- 气泡会根据屏幕边界调整布局，同时保持靠近桌宠且不与桌宠重叠
- 桌宠与主窗口共用角色、会话和消息记录
- 可从模型设置或系统托盘开启、关闭 Windows 开机自启
- 程序采用单实例运行，重复启动只会唤醒已有窗口，不会重复启动本地服务

### 角色主动互动插件

在展开界面“模型设置”启用角色主动互动插件，并保存设置。默认关闭；启用后会调用已配置的模型 API，消耗输入及输出 token。可设置 1–1440 分钟调用间隔和 64–1024 输出 token 上限；选择固定间隔或随机浮动 ±15%。保存新间隔会按比例调整剩余冷却，不会清空冷却。23:00–07:00 静默，桌宠隐藏或正在操作面板时不触发，轮询最多延后约一分钟。间隔越短，消耗越高。

问题、笑话会结合完整角色卡和本机时间生成，并作为助手发言保存到角色对话。可选新闻话题使用 HTTPS RSS，只使用最近 48 小时的有日期新闻，记录来源链接；源失败则退回问题或笑话。默认使用[中新网官方即时新闻 RSS](https://www.chinanews.com.cn/rss/)，可更换可信来源；它是近期新闻，不是社交平台热搜排名。累计 token 依赖服务返回的 usage 数据。

桌宠动作新增前空翻、后空翻独立透明素材及透视翻转动画。

### 离线翻译

- 基于 Argos Translate 提供中文与英文双向翻译
- 中英、英中语言包可按需单独下载
- 下载时显示实时百分比，并在下载完成后提示语言包安装进度
- 语言包安装完成后无需联网，模型保存在安装目录中
- Windows 桌面版支持连续翻译：开启后，在其他应用中用鼠标选中文本即可自动识别方向并显示译文

语言包下载前会并行测速已配置镜像、Argos 数据站和官方索引使用的备用源，自动选择更快的可用地址。下载支持 `.part` 文件断点续传、单源三次指数退避重试，以及失败后自动切换下一来源；界面会显示测速、重试、续传、下载和安装状态。中国大陆网络访问较慢时，可在“模型设置 → 离线翻译下载”填写可信镜像的基础地址，镜像目录必须包含与官方同名的 `.argosmodel` 文件。为避免模型被替换，请只使用自己维护或可以验证来源的镜像。

#### 使用连续翻译

1. 单击桌宠，打开功能圈中的“翻译”。
2. 如果尚未安装当前方向的语言包，先点击下载；下载成功后状态会立即刷新。
3. 点击翻译框顶部的“○ 连续”，显示为“● 连续”即表示已经开启。
4. 切换到浏览器、记事本或其他应用，用鼠标选中一段中文或英文。
5. 桌宠会自动识别中英文方向，并在翻译框中更新原文和译文。

选择桌宠翻译框自身的文字不会触发新翻译。关闭翻译框、隐藏桌宠或返回主界面时，连续翻译会自动停止。

## 安装与使用

项目当前提供 Windows NSIS 安装包。自行构建后，安装包位于：

```text
frontend\src-tauri\target\release\bundle\nsis\Yus AI_0.13.6_x64-setup.exe
```

安装后无需打开终端，直接启动 **Yus AI** 即可：

1. 从系统托盘打开主界面。
2. 创建或导入一个角色。
3. 在“模型设置”中填写兼容 API 地址、API Key 和模型名称。
4. 返回聊天页面创建对话并发送消息。

### 消息显示插件

在“模型设置 → 消息显示插件”中选择一种模式，然后点击“保存设置”：

- **Markdown 渲染**：默认模式，将模型回复中的格式转换为标题、列表、表格、引用和代码块
- **Markdown 过滤**：移除常见 Markdown 标记，只显示纯文本
- **原始文本**：不做处理，完整显示模型返回的标记，适合调试提示词和输出

三种模式互斥，不会发生先渲染再过滤的冲突。当前选择保存在 SQLite，桌宠回复也会同步使用。

关闭主窗口不会退出程序，而是切换回桌宠模式。需要彻底结束程序时，请在系统托盘右键菜单中选择“退出”。托盘菜单也可以显示或隐藏桌宠，并调整桌宠大小和透明度。

### 开机自启与单实例

- 在“模型设置 → 系统启动”或系统托盘菜单中开启、关闭开机自启
- 开机启动后直接进入桌宠模式，并恢复上次保存的位置
- 连续点击快捷方式不会启动第二个程序、第二个后端或第二个托盘图标
- 再次启动时，如果主界面已经显示则将它置前，否则显示现有桌宠
- 启动项写入当前用户的 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`，不需要管理员权限
- 覆盖升级会保留自启选择，并在安装路径变化时修正启动路径；卸载会清除相关注册表项

## 本地数据与隐私

桌面版的运行数据保存在软件安装目录中，覆盖安装或升级时不会删除：

```text
<安装目录>\data\yus_ai.db
<安装目录>\data\translation-models\
<安装目录>\data\character-exports\
<安装目录>\data\temp\
<安装目录>\logs\
```

- `yus_ai.db`：角色、会话、消息、设置、桌宠位置和记忆
- `translation-models`：离线翻译语言包
- `character-exports`：导出的角色卡
- `logs`：后端运行日志和诊断信息

首次运行新版时，如果安装目录内还没有数据库，程序会尝试从旧版 Windows 用户应用数据目录复制已有数据，并保留旧文件作为备份。

从 0.13.3 开始，`yus-ai-backend.exe` 必须与安装目录的 `backend-runtime` 文件夹配套，不能单独移动后端 EXE。升级会更新运行库，保留 `data` 中的数据库、语言包和角色导出。Windows/WebView 自身仍可能使用系统缓存，本改动消除的是后端每次启动的大量解压。

旧版本残留清理（先预览；确认后加 `-Clean`，删除的是可重新生成的运行库，不可从回收站恢复）：

```powershell
.\scripts\clean-legacy-backend-temp.ps1 -TempDirectory 'C:\Users\你的用户名\AppData\Local\Temp' -InstallDirectory 'E:\Tools\Yus\Yus AI'
```

脚本使用当前旧版运行库或已安装新版的 `backend-runtime` 提供可信指纹，保留当前使用的解压目录；无法确认归属的目录不会删除。

日志不会记录 API Key、Authorization Header、聊天正文或系统提示词。需要排查问题时，可参考 [调试接口](docs/DEBUG_API.md)。

> 注意：API Key 当前保存在本地 SQLite 数据库中，尚未接入 Windows Credential Manager。请勿将 `data`、`logs` 或本机配置文件上传到公开仓库。

## 本地开发

### 环境要求

- Windows 10/11
- Node.js 20+
- Python 3.10+
- Rust 与 Tauri 2 所需的 Windows 开发环境

### 启动后端

在项目根目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r backend\requirements.txt
cd backend
..\.venv\Scripts\python -m uvicorn app.main:app --reload
```

后端地址为 `http://localhost:8000`，交互式接口文档位于 `http://localhost:8000/docs`。

### 启动网页开发界面

另开一个终端：

```powershell
cd frontend
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`。网页开发模式主要用于界面调试，不包含完整的桌宠、系统托盘和原生文件能力。

### 启动桌面开发模式

先构建本地后端 sidecar：

```powershell
.\.venv\Scripts\python -m pip install -r backend\requirements-build.txt
.\scripts\build-backend.ps1
cd frontend
npm run desktop:dev
```

### 生成 Windows 安装包

从项目根目录开始，先重新打包后端，再构建桌面安装包，避免把旧版后端带进新版安装包：

```powershell
.\scripts\build-backend.ps1
cd frontend
npm run desktop:build
```

构建脚本会生成后端 EXE 和 `backend-runtime` 运行库，Tauri 安装包会同时打包两者。安装包、运行库及构建缓存不提交到 Git，源码和桌宠动作素材随工程提交。

## 测试

前端构建：

```powershell
cd frontend
npm run build
```

后端测试：

```powershell
cd backend
..\.venv\Scripts\python -m pytest -q
```

打包后可从项目根目录核验目录式运行库：

```powershell
.\.venv\Scripts\python scripts\check-backend-bundle.py
```

此检查核验依赖布局及不生成 `_MEI` 解压目录；已有本地服务时使用隔离数据目录验证启动和预期的端口占用退出，不替换现有服务、不调用模型。独立验证新闻源可运行 `scripts/check-proactive-news.py`，需要联网但不消耗模型 token。

0.13.3 发布构建已通过 12 项后端测试、前端构建、Rust 检查、目录式后端核验及 Windows NSIS 打包；这不代表所有用户机器上的安装环境都已验证。

0.13.6 当前构建已通过 16 项后端测试和前端构建，覆盖流式持久化、手动取消主动生成、随机时间区间、来源隔离与生成互斥。

网页开发模式的数据写入 `backend/data/yus_ai.db`；桌面版数据写入软件安装目录，两者均已加入 Git 忽略规则。

## 当前限制

- 当前只提供 Windows 桌面安装包
- 本地后端固定监听 `127.0.0.1:8000`
- API Key 暂时以本地数据库形式保存
- 目前内置能力包括 Markdown 显示/过滤、离线翻译及角色主动互动；通用第三方插件系统仍在逐步建设
- 主动互动默认关闭；启用后会调用已配置的模型并可能计费，包含失败重试。面板展开、桌宠隐藏和本地时间 23:00–07:00 不触发新的主动调用
- 0.13.3 解决后端启动解压残留，不是运行内存优化；Windows 和 WebView 自身仍可能使用 C 盘缓存
- 连续翻译依赖目标应用支持标准 `Ctrl+C` 复制；管理员窗口、受保护页面或特殊绘制界面可能无法读取选区
- 连续翻译可恢复原来的文本剪贴板；如果原剪贴板只有图片或文件，目标应用执行复制后可能改变剪贴板内容
