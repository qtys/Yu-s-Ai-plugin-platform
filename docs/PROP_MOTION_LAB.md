# 道具与连接轨迹实验

预览：`http://127.0.0.1:5173/prop-lab.html`。运行方式、隔离的8001端口及只读安装配置，与 [像素实验](PIXEL_MOTION_LAB.md) 相同。

保留现有爱丽丝头部原画，不修改正式桌宠。模型通过现有实验接口的 `mode=prop` 输出新矢量道具与连续轨迹；原画没有手、腕或身体，因此当前演出是漂浮杯喝水，不能声称已实现手持抓握。

## 工具原语

第二版已取消“必须嘴部接触、必须倾斜喝水”的限制。模型可生成不同的单一道具，选择 `mouth`、`left_eye`、`right_eye`、`forehead` 节点，或仅在 `stage` 漂浮。身体节点按头部实时角度计算，同节点持续连接时不插值错误的世界坐标；连接与释放仍连续过渡。

预览提供放大镜、饼干、王冠的文字建议，不提供相应预置动画。生成成功的结果可以在当前页面内存列表中重播，重播不消耗token，刷新会清空。放大镜目前只是透明镜片的观察动作，没有光学放大；饼干能靠嘴停留，但不会真正被咬掉缺口。

- 道具绘制：数值路径段定义直线、二次曲线、三次曲线；杯口原点为(0,0)。颜色只能为六位十六进制，无脚本、远程图片或任意SVG标记。
- 移动：时间轨迹插值，不选择固定喝水动画。
- 连接：mouth节点由原画坐标标定；接触帧x/y必须为0。先解析节点位置再插值，切换绑定不会瞬移。
- 旋转：杯子围绕杯口转动，头部围绕同一嘴部节点轻微旋转，保持接触点一致。
- 释放：道具回到舞台空间并消失；首尾无道具，以衔接原待机。

页面首段为明确标注的手绘连接校准。点击生成才调用当前文本模型绘制新路径及轨迹，消耗token；只发送输入文字，不读取聊天历史，不写入聊天记录。失败保留上一段预览，不以模板代替真实结果。

## 限制

这是单道具与头部节点交互的概念验证，不是任意物体行为系统或已集成的聊天工具调用。模型生成的是矢量素材，而非绘图模型生成的位图；交互点是否真正画在原点、画风及动作语义仍需视觉检查。道具几何在播放中固定，没有液体物理、光学效果、自动遮挡规划、手部IK或持久道具存储；正式集成需进一步实现这些能力。现有角色资产许可不会因为实验改变。
