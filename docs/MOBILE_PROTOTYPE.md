# 手机端原型（第一阶段）

这份文档记录最初的“连接电脑后端”预览：在电脑上访问 `http://127.0.0.1:5173/mobile.html`。该页面不是 Android APK，开发时默认连接 `http://localhost:8001/api`。

之后增加了真正独立运行的手机端工程，见 [ANDROID.md](ANDROID.md)。独立版在电脑上的开发预览地址是 `http://127.0.0.1:5174/`，不依赖电脑上的 Python 后端。

本阶段复用现有角色、最近对话和流式聊天接口。插件注册表新增平台标识，移动端开关按设备 ID 单独保存，不覆盖桌面端开关。消息显示、对话环境信息、小说式回复、二次审核先可用；桌宠主动互动与 Argos 离线翻译标记为桌面专用。消息显示方式只保存在本设备浏览器中。

这个旧预览所使用的后端只监听电脑本机，没有移动设备鉴权、TLS 和跨设备发现；**不要将 API 端口直接暴露到局域网或公网**。它与独立 Android 工程不是同一个数据空间。
