### 已知限制

- 当前只提供 Windows 安装包。
- 桌面后端固定监听本机 `127.0.0.1:8000`。
- API Key 目前存储于本地 SQLite，尚未接入 Windows Credential Manager。
- 关闭窗口会隐藏到托盘，需要从托盘菜单选择“退出”才能彻底停止程序。
- 安装升级前必须退出旧版，否则 Windows 会锁定后端可执行文件。
