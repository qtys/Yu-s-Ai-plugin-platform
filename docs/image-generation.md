# 图片生成插件

在展开界面的「模型配置 → 绘图模型」展开配置并启用绘图能力。修改后自动保存，不再作为插件卡片展示。原有连接、密钥与启用状态保留。

## 配置

- 连接：独立输入 API 基础地址、密钥；也可选择现有模型连接，复用它的地址与密钥。
- 绘图模型名称：必须是服务商支持的图片生成模型 ID，聊天模型不一定支持绘图。
- 默认尺寸、质量：按服务商和模型支持情况选择；质量选「服务默认」时不发送该参数。
- 返回格式：优先使用「服务默认」。GPT Image 不需要显式指定返回格式；其他兼容服务可选择 `b64_json` 或 `url`。
- 代理：生成请求可自动读取系统 HTTP/HTTPS 代理，或使用直连。

首版适配 `POST {base_url}/images/generations`，接受 `data[].b64_json` 或 `data[].url`。可直接粘贴完整接口地址，保存时会去掉末尾接口路径，避免重复拼接。专用异步任务接口、Gemini 原生接口、图片编辑和视频生成不在本版适配范围。

接口格式参考：[Images API 文档](https://developers.openai.com/api/reference/cli/resources/images/methods/generate)。

## 使用与数据

启用后，在对话输入框旁点击绘图图标，将下一次提交切换为图片生成：直接在原输入框填写描述、画风与构图，点击发送即可生成图片，不再弹出独立绘图窗口。图标底色表示选中状态，不显示额外提示条。生成成功后自动恢复普通聊天；失败时保留输入，方便检查和重试，也可以再次点击绘图图标退出本次绘图模式。

也可以点击某条消息旁的「生成图片」，明确选择这条内容；若先选中了该消息中的一段文字，则仅使用选中片段。这种从已有消息生成图片的方式仍提供弹窗：来源内容只读展示，额外指令可单独填写画风、构图、人物细节等要求。

生成成功后，绘图请求及图片消息一并保存在原对话中，关闭重开仍可查看，支持查看原图、保存 PNG 和撤回。绘图描述与额外指令可在图片下展开查看。作品库仍保留最近 24 张图片；撤回消息或删除对话不会删除作品库中的图片。生成过程中切换对话不会把图片加入新对话；原对话若已删除，图片仅保留在作品库。

生成仅提交明确指定的消息/片段或填写的图片描述、额外绘图指令及绘图参数，不自动上传整段聊天历史、角色卡、文档或屏幕内容，不自动触发生成。不影响当前聊天模型。加入对话后的文字描述会作为后续聊天上下文，但不会自动把图片像素提交给聊天模型，不能将文字描述当作视觉理解结果。

图片文件保存到应用数据目录的 `generated-images` 文件夹，提示词和模型信息保存在同一目录下的数据库；正式 Windows 安装版使用安装目录内的 `data` 文件夹。图片随数据备份和恢复一起处理，升级不主动删除。

图片链接只下载公网 HTTPS 图片，不跟随重定向，不向图片下载地址发送 API 密钥。CDN 下载目前使用直连；若服务只提供无法直连的图片链接，可尝试支持 Base64 返回的服务。

DNS 同时返回公网及非公网地址时，只固定连接已校验的公网地址。若仅返回内网地址或代理 Fake-IP（常见 `198.18.0.0/15`），仍拒绝下载：请为对应 CDN 域名使用真实公网 DNS 解析，或选择服务支持的 `b64_json` 返回格式，避免链接下载环节。不会为兼容代理而放开内网访问，也不会自动再次付费生成。

生成诊断记录在 `logs/plugins/image_generation.log`，包括操作编号、接口状态、服务错误码/请求 ID，以及响应解析、Base64 解码、图片下载、图片解码、保存等失败阶段。DNS 日志记录域名、解析数量、公网/拦截数量与 Fake-IP 网段判定；不记录生成描述、密钥、图片正文或签名查询参数。

## 失败与费用

每次生成可能产生服务商费用。不会自动重试生成请求；请求超时或图片下载失败时，服务端可能已经生成并扣费，请先检查服务商记录，再决定是否重试。软件本地没有按生成次数收费。

本版完成的是接口适配和模拟服务测试。实际服务兼容性需要填入自己的绘图 API 后验证；本次开发没有使用私人密钥进行付费生成。
