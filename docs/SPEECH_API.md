# 在线语音输入与朗读（Windows 0.15.30）

在展开界面顶部“插件 → 效率工具”启用“语音输入与朗读”，点击卡片配置。修改后自动保存，识别与合成分别保存，不影响聊天模型配置。

## 配置

- 识别：API 基础地址、密钥、语音识别模型 ID。
- 合成：API 基础地址、密钥、语音合成模型 ID、音色 ID、语速。
- 地址填写服务商的基础地址，例如 `https://api.example.com/v1`，不要填写聊天接口或完整 audio 路径。
- 服务必须支持 OpenAI 格式的 `POST /audio/transcriptions`（multipart，JSON text 返回）和/或 `POST /audio/speech`（JSON，MP3 返回）。不是所有提供聊天 API 的服务都提供语音功能。各字段填服务商实际支持的值，不自动复用聊天密钥。
- 可只配置其中一项，另一项使用时会提示未配置。

接口依据：[语音识别](https://developers.openai.com/api/reference/cli/resources/audio/subresources/transcriptions/methods/create)、[语音合成](https://developers.openai.com/api/reference/cli/resources/audio/subresources/speech/methods/create)。不兼容此格式的供应商需要另加适配器。

## 使用与边界

### 网络连接（0.15.29）

语音设置支持“自动使用系统代理”和“直连”。自动模式读取环境变量或 Windows 静态 HTTP/HTTPS 系统代理，遵守绕过规则，本机服务始终直连；不执行 PAC 脚本、不支持 SOCKS 代理，不关闭 TLS 证书校验。代理须保持运行。

基础地址也支持粘贴完整 `/audio/transcriptions` 或 `/audio/speech` 地址，保存及读取旧配置时自动移除末尾接口路径，避免重复拼接。两个语音接口共用网络模式，但仍使用各自的地址、密钥与模型。

“检查网络连接”只发送不带密钥、录音或朗读文本的 GET 请求，不发起识别/合成。HTTP 404 等响应也意味着服务器可达，不代表密钥、模型或语音接口可用；实际效果仍须录音或试听验证。连接失败日志增加 TLS/超时/连接分类及是否使用代理，不记录敏感配置。

展开聊天提供语音输入；桌宠轻量输入框不再提供录音和朗读按钮。点击开始、再次点击结束并识别，文字追加到输入框，可修改后再发送。单次最长 60 秒、10 MB；录音与识别均可取消。切换对话、停用插件或开始聊天会取消当前录音与播放，避免内容串到别的对话。

展开界面每条已保存的 AI 回复有“朗读”按钮。长回复按句子分段请求并依次播放，不静默截断，单次朗读上限 3 万字符。停止会取消前端待处理请求和播放，但已经发送给服务商的请求不保证停止计费。

目前仅接入桌面/浏览器端，Android 原生麦克风权限与 UI 后续适配。浏览器预览应使用 localhost 或 HTTPS；拒绝麦克风权限时需要在系统/浏览器设置重新允许。

插件默认关闭，不持续监听，不自动发送文字，不自动朗读主动发言。声音为 AI 合成。录音上传给配置的识别服务、朗读文字提交给合成服务，可能产生服务费用。密钥在本地数据库保存、接口读取时遮盖；请保护数据库和备份。录音和生成音频只临时驻留内存，不写入长期文件，也不写入聊天记录。日志仅记类型、状态与字节数，不记录音、文字、密钥或服务商错误正文。

## 回归检查

1. 配置识别，开始录音，确认系统麦克风提示；说中文，结束录音，确认文字进入输入框但没有发送。
2. 取消录音/识别，切换对话，确认旧结果没有进入新对话。
3. 配置合成，试听；朗读已编辑回复，停止，确认停止后不会继续播放下一段。
4. 验证无密钥/错误地址/限流会显示可理解的提示，不泄露密钥。
5. 桌宠、展开界面、四个主题，检查按钮和长错误提示没有超出边界。
6. 插件停用后无录音/朗读按钮，后端语音请求也被拒绝。

自动测试使用模拟语音服务，不需要真实密钥、不产生费用。真实录音/音色与供应商联调仍需填写配置后验证。
