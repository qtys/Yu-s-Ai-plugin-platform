# 插件基础框架（开发中）

从 `v0.15.13` 本地安装包起提供**可信内置插件**注册与启停基础。暂不支持从外部目录安装或执行第三方 Python、JavaScript 插件。

## 现有内置插件

| ID | 功能入口 | 停用后的行为 |
| --- | --- | --- |
| `translation` | 桌宠翻译功能圈、语言包下载与翻译 API | 隐藏翻译功能圈，新的翻译及下载请求返回 409；已下载语言包不删除 |
| `message_display` | 主界面与桌宠的回复显示 | 回复按原始文本显示；原先选择的显示模式保留，重新启用后恢复 |
| `proactive` | 桌宠主动互动 | 停止新的模型调用与本地问候，取消正在执行的主动生成；原有配置和历史消息保留 |

插件启停状态保存在安装目录 `data/yus_ai.db` 的 `plugin_states` 表中，默认全部启用；主动互动插件中的“启用主动模型调用”仍是独立的使用开关。数据库备份与恢复会包含这些状态。

## 注册与调用约定

1. 在 `backend/app/plugins.py` 中注册 `PluginManifest`：稳定 ID、名称、版本、入口位置、所需能力、默认状态。重复 ID 会被拒绝。
2. 功能入口必须在执行实际操作前检查 `is_enabled`；不能只在界面隐藏按钮。关闭时应取消或停止相关后台任务。
3. 对桌宠/主界面提供的入口，通过 `GET /api/plugins` 返回的状态控制显示与行为。状态修改走 `PUT /api/plugins/{id}/state`，请求体为 `{"enabled": true|false}`。
4. 新插件至少补齐启用、停用、重启持久化、直接调用 API 绕过界面的测试。

`permissions` 目前是**能力声明**，用于让用户看清插件可能访问什么，不是操作系统沙箱授权。第三方插件加载、签名校验、独立进程隔离和细粒度权限授予，需在开放外部安装前设计并实现。
