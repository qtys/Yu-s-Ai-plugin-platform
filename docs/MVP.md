# Yu's AI MVP 产品规格

## 产品目标

第一版是一款本地优先、开箱可用的个人 AI 聊天工具。用户配置一个兼容 OpenAI API 的服务后，可以创建角色、持续对话，并在重新启动后保留全部数据。

## 核心用户流程

1. 配置 API 地址、密钥、模型和生成参数。
2. 创建或选择角色，填写名称、简介和系统提示词。
3. 新建会话并进行流式聊天。
4. 自动保存角色、会话和消息。
5. 从历史会话继续聊天。

## MVP 范围

- OpenAI Chat Completions 兼容接口
- 角色创建与选择
- 多会话和本地消息历史
- 流式输出、停止生成
- SQLite 本地持久化
- 响应式桌面/手机界面
- API 配置和基础生成参数

暂不包含插件市场、任意第三方代码执行、账户系统、云同步、向量数据库及原生移动客户端。

## 后续阶段

1. 消息编辑、重新生成、数据导入导出。
2. 翻译、对话摘要和用户可见的长期记忆。
3. 将稳定的输入处理、上下文组装和输出处理能力抽象为插件钩子。

## 数据与隐私原则

- 数据默认只存储在用户本机。
- 长期记忆必须可查看、编辑、禁用和删除。
- 插件不能直接访问宿主数据库，未来通过受控 API 获取能力。
- MVP 的 API Key 存在本机 SQLite 中；提供远程部署前需增加系统密钥链或加密存储。
