# 生成式像素史莱姆实验

预览入口：`http://127.0.0.1:5173/pixel-lab.html`。这是独立实验页，目前不替换正式桌宠、不自动接入聊天或主动发言。

## 启动

在工程根目录打开两个 PowerShell 终端。后端使用单独端口与实验数据目录：

```powershell

# 可选：填写现有安装的数据库绝对路径，仅以 SQLite mode=ro 读取模型连接与角色。

cd backend
..\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8001
```

```powershell
cd frontend
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

如果没有指定既有数据库，可以用实验后端的 `/api/settings` 配置模型。前端仅读取模型名、是否已配置、角色 ID 和名字，不读取模型密钥。`VITE_PIXEL_API_URL` 可以指定其他实验接口地址。

## 原理与验证方式

### 第二版：受保护造型 + 柔软扇叶

默认预览现在使用固定圆润水滴造型、重新绘制的五官和蓝色扇叶。身体不再由模型顶点决定，扇叶固定连接在身体后侧，限制摆动范围并要求首尾完全收回，防止切开脸部和凭空漂浮。

模型以 `mode=soft` 创作扇叶伸展、展宽、弯曲、摆动及五官的时间轨迹，不选择预设动画名称。但这是**一个受限的扇叶动作试验**，不是任意新道具或任意基础形状的自由生成：扇叶的基本美术曲线由渲染器定义。先确保这个效果好看，再逐步扩展生成空间。

样例01是新版手绘美术校准，其余为第一版对照。点击生成才是真实模型输出；旧的自由轮廓接口仍可用 `mode=free` 测试。正式桌宠未替换。

### 第一版：自由轮廓实验

- 模型输出声明式 JSON：身体轮廓顶点、五官连续参数、多边形/椭圆/线条道具及它们的逐帧变化。
- 同一图层的顶点数固定，但每个顶点可以独立移动；在 96×96 透明 Canvas 上重新绘制，整数倍放大。图层可跟随身体，也可独立移动；支持前后遮挡与出现/消失。
- 渲染器使用局部平滑插值；它保证时间连续，不自动保证画得好看、轮廓不穿插或物体接触正确。
- 所有关键帧有数量、时间顺序和数值限制，重复 ID、无穷值、拓扑不一致等会被拒绝。后端不执行模型代码，输出额外脚本字段也会被拒绝。
- 三个内置场景是手绘引擎测试数据，页面明确标注。点击“让模型创作新表演”才调用当前模型；失败保留旧预览，不用模板伪装成模型输出。
- 只发送本轮文本及可选的角色设定，不读取历史聊天，不写入会话。每次生成消耗模型 token；单次输出上限 8000 tokens。页面“取消等待”取消浏览器等待，模型服务端可能继续执行已经提交的请求。
- 对 DeepSeek 官方接口使用 JSON 输出并关闭思考模式，避免思考过程耗尽动画输出预算；其他兼容接口不附加 DeepSeek 专有参数。[官方参数说明](https://api-docs.deepseek.com/guides/thinking_mode/)。日志仅记录结束原因、输出长度、token 数及错误类型，不记录密钥、角色内容或完整模型输出。
- 格式校验失败时最多请求模型修正一次，会额外消耗 token；整段生成最多等待80秒。修正仍失败不会播放不合格数据，也不会偷偷退回模板。这里的修正是结构校验，不是语义或审美审核。
- 通过暂停、慢放、时间轴和 JSON 编辑检查新的轮廓变化、道具形状与接触关系。可导出当前动画；模型生成的数据不自动写入仓库。

## 当前边界

当前是连续轮廓与自由道具绘制的第一版：身体仍是一条闭合轮廓，颜色表固定，五官形状由连续参数控制。复杂遮挡、真实碰撞、多身体部件和视觉自检尚未实现；生成式不等于任意行为都能正确表演。下一步应根据真实生成效果改进接触约束与造型，再决定是否整合到桌宠。

测试：`cd frontend; npm run test:pixel`；后端：`cd backend; ..\.venv\Scripts\python.exe -m pytest tests/test_pixel_motion.py -q`。
